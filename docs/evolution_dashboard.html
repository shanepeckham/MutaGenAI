What makes MutagenAI different from naive prompt optimization:
① Adaptive mutations — error analysis drives targeted fixes, not random rewrites
② CMA-ES co-evolution — temperature & top_p evolve alongside the prompt text
③ Error decay (0.5×/gen) — stale corrections fade; only persistent errors remain influential
④ Elite preservation — the best prompt is never lost. Population can only stay same or improve

Strategy Guide
When to use which scoring strategy
Composite scorer wins consistently. Blending LLMJudge + ToolSuccess + ProxyMetrics avoids overfitting to any single signal. On API-Bank it reaches 82.3% (vs default 55.0%) without ever seeing a ground-truth label. Self-Consistency is the best single strategy — fast and effective at 81.8%.
